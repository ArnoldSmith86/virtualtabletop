# Hanafuda card images

The card images in this directory are by Louie Mantia and すけじょ and are
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

They were downloaded from Wikimedia Commons, category
[SVG Hanafuda with traditional colors (black border)](https://commons.wikimedia.org/wiki/Category:SVG_Hanafuda_with_traditional_colors_(black_border)).
Each file `MM-<type>.svg` corresponds to the Commons file
`Hanafuda <Month> <Type> Alt.svg` (e.g. `01-hikari.svg` is
`Hanafuda January Hikari Alt.svg`); `back.svg` is `Hanafuda card back Alt.svg`.

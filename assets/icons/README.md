# Icons

Icons used by the client UI, by widget properties like `svgReplaces` and by the
ready-made decks in `../decks/`.

`star.svg` is the same drawing as `../game-icons.net/delapouite/round-star.svg`,
recoloured to `currentColor` so it can be tinted like the `clubs.svg`,
`diamonds.svg`, `hearts.svg` and `spades.svg` suit symbols next to it. It is
used as the trump symbol of the tarot deck.

Players and connections

Every browser tab that has this room open is one connection of a player. Edit the name and color of any player, view the game as another player or add a local player that shares this device. While you have this room open in more than one tab, adding a player switches the current tab to them, so every tab can be its own player.

share

Remote play

Everybody plays on their own device: send them the room URL with the share button in the table above and they join this table as soon as they open it. Their browser tab shows up here as a connection and they can pick their name and color in the table.

swap_horizontal_circle

Hotseat

Several people share one device: add each of them with the person_add row of the table, then use the visibility button to switch this browser tab to whoever's turn it is. Only this browser tab switches over, the game itself stays untouched.

Add game

Upload VTT or PCIO files you downloaded from the web, or a Tabletop Simulator workshop ZIP file.

You can find compatible game files on a boardgamegeek.com geeklist, the PlayingCardsIO subreddit, its notion.so database or GitHub.

Please note that PCIO files might not be 100% compatible. Please open an issue on GitHub if a file is unplayable.

If you have a direct link to a VTT or PCIO file (for example by sharing a link from virtualtabletop.io), you can add the game using the link and you will always play the latest version.

You can also enter a Tabletop Simulator workshop link in order to import the widgets from it, but the imported game will not have any automation.

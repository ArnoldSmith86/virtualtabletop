Decks in the public library

Click a deck to add a copy of it - including a holder, all its cards and a shuffle button - to your game. Some decks appear differently than in their game due to CSS or fonts not available within the deck widget itself.

Print or save deck as PDF

Cards are arranged to use as much of each sheet as possible. Print to a printer or choose “Save as PDF” in the browser print dialog. Front/back output alternates mirrored pages; enable two-sided printing with the matching duplex flip setting.

Import card types from CSV

Choose a CSV file to import from. This will not import other deck data such as face objects. This makes each row in the CSV a card type; the id::INTERNAL column sets its name and cardCount::INTERNAL sets how many cards of it are in the game. To generate a CSV file with the appropriate data, use the save icon in the upper left.
